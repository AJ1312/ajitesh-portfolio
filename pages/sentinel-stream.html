Key Technical Innovations

  • O(1) Streaming Profiler: Replaces raw event arrays with Exponentially Weighted Moving Averages (EWMA) and Count-Min Sketch tables ($4 ext{ KB}$ matrix), bounding memory per entity.
  • Zero Cold-Start Vulnerability: Stage 1 Isolation Forest calculates structural anomaly scores ($s_{ ext{iso}}$) for newly onboarded entities without historical baseline logs.
  • Inline TreeSHAP Explainability: Computes exact directional feature risk attributions in $pprox 30\ \mu ext{s}$ per alert.

The Real-World Scenario

Enterprise Security Operations Centers (SOCs) ingest tens of millions of audit events daily. Existing UEBA solutions store historical raw event arrays per user, causing memory consumption to scale linearly $O(N)$ and leading to Out-Of-Memory (OOM) failures under burst traffic.

SENTINEL-STREAM guarantees strict $O(1)$ memory consumption per entity while rendering sub-3ms anomaly classification with exact TreeSHAP feature attributions.
