INTERNSHIP CERTIFICATE — Hindalco Industries Ltd., Aditya Birla Group

The Brief

Hindalco's Renukoot smelting complex runs 24/7 operations with over 1,200 site personnel across shifts. Employee scheduling was entirely paper-based — supervisors maintained handwritten rosters, assignment changes propagated through physical notice boards, and status updates required in-person communication. The result: scheduling conflicts, delayed updates, and zero real-time visibility into workforce allocation.

The Solution

1. Automated Role-Based Queue Management Platform

  • Digitized the entire paper-based scheduling process.
  • Real-time status updates for all 1,200+ site personnel.
  • Role-based access: Operators view their queue position, Supervisors manage assignments, Managers have full visibility.
  • Digital notice board replacing physical bulletin boards entirely.

2. Spring Boot REST API Architecture

  • Developed highly scalable RESTful APIs for queue management, status updates, and reporting.
  • Seamlessly integrated with existing on-premises Oracle database infrastructure.
  • Generated comprehensive endpoint documentation for the plant IT team for future maintenance.

3. PL/SQL-Enforced Role-Based Access Control

  • 15 internal Oracle APEX reporting endpoints secured.
  • Database-level security enforcement to ensure integrity independently of the application layer.
  • Defined strict Role hierarchy: Worker < Supervisor < Plant Manager < Admin.
  • Implemented robust audit logging for all access requests and database modifications.
